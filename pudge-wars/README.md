# 钩肥大战 (Pudge Wars) — War3 RPG 网页复刻版

经典《魔兽争霸3》RPG 地图《钩肥大战》的纯前端零依赖网页复刻项目，包含完整可玩游戏、解耦逻辑引擎、15 项自动化单元测试、蒙特卡洛 AI 平衡性仿真器与技术报告。

## 快速开始

### 1. 直接游玩
用任意现代浏览器双击打开 `index.html` 即可开始游戏，无需构建或安装依赖。

- **移动走位**：`WASD` / 方向键，或 `鼠标右键` 点击地面（右键点击同岸敌人将自动追击平A）
- **发射肉钩**：`鼠标左键` 或 `Q`
- **紧急滑步 / 闪烁**：`E` 或 `Space`
- **钩子四维升级**：`1` 伤害 / `2` 长度 / `3` 速度 / `4` 半径
- **装备商店**：`B`

### 2. 运行测试与平衡性模拟
需要 Node.js 16+：
```bash
npm test
```

## 目录结构
- `index.html`：完整单文件网页游戏（Canvas 2D + Web Audio 合成音效 + 触屏适配）
- `src/engine.js`：解耦的核心游戏引擎与平衡性常量（v2.3）
- `tests/test_and_balance.js`：15 项核心机制单元测试 + 多模式/多流派蒙特卡洛仿真
- `docs/TECHNICAL_AND_BALANCE_REPORT.md`：架构设计、测试覆盖与三轮平衡调优技术报告
