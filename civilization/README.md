# 文明：纪元演进（Web Civilization）

一款基于原生 HTML5 Canvas、ES Modules 与 Web Audio API 构建的零依赖网页版 4X 回合制策略游戏完整工程。包含模块化源码、自动化测试套件、单文件构建工具与完整技术报告。

## 核心特性

- **可复现六边形世界**：基于 Mulberry32 PRNG 与多倍频分形值噪声生成包含 9 种地形与 6 种战略/奢侈资源的六边形世界，支持自定义种子复现。
- **完整 4X 玩法闭环**：探索（战争迷雾与视野系统）、扩张（开拓者建城与人口疆域扩张）、开发（建造者农田/矿山/商站改良、城市排产与金币速买、三时代 10 项科技树）、征服（近战/远程/攻城战斗与城市占领、外交宣战与议和）。
- **AI 文明对手**：支持最多 4 大特色文明同台竞技（华夏、罗马、埃及、雅典），AI 具备自动选址建城、兵种生产、科技研发、地块改良与战术攻防能力。
- **三种胜利条件**：征服胜利、科技胜利（建成「大天文台」）、100 回合积分胜利。
- **离线即玩与本地存档**：支持一键构建为单文件 HTML（零外部依赖，双击即玩），内置 Web Audio 合成音效与 `localStorage` 本地存档/读档。

## 快速开始

### 1. 直接游玩（推荐）
直接用任意现代浏览器打开 `dist/web-civilization.html` 即可开始游玩，无需安装任何依赖或启动服务器。

### 2. 运行自动化测试（需 Node.js >= 18）
```bash
npm test
```

### 3. 重新构建单文件发行版
```bash
npm run build
```

## 快捷键

- `WASD` / `方向键`：平移地图视角（或鼠标拖拽）
- 鼠标滚轮 / `＋` `－`：缩放地图
- `Tab`：切换下一个待命单位
- `B`：选中开拓者时建立城市
- `F`：战斗单位驻守回血
- `T`：打开科技树
- `Space` / `Enter`：结束当前回合
