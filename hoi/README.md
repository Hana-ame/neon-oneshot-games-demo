# Web HOI — 1936 欧洲战区网页版大战略游戏

一个零外部运行时依赖、模块化架构的网页版《钢铁雄心》（Hearts of Iron）大战略游戏项目，完整实现 1936 年欧洲战区 25 省战略地图、6 大主要国家、陆军战斗与装甲穿甲结算、BFS 补给枢纽追踪、工业建造与军工产线、科技树、国家焦点树、阵营外交与国家 AI，并附带自动化测试套件与单文件离线构建脚本。

## 快速开始

### 方式一：直接双击离线游玩（推荐）
直接用现代浏览器打开 `dist/web-hoi-standalone.html` 即可开始游戏，无需安装任何依赖或启动服务器。

### 方式二：本地开发服务器运行模块化源码
```bash
# 启动静态服务器
npm start
# 在浏览器访问 http://localhost:8080/index.html
```

### 运行自动化测试与重新打包
需要 Node.js 18+：
```bash
# 运行全部 18 项单元与集成测试
npm test

# 重新将 src/ 内联构建为单文件版本 dist/web-hoi-standalone.html
npm run build
```

## 基础操作指南
- **选择国家**：通过左上角下拉菜单在德意志国、苏维埃联盟、法兰西共和国、联合王国、意大利王国、波兰第二共和国之间切换。
- **时间推进**：点击顶部 `▶ 开始 / ⏸ 暂停` 或按 `空格键` 控制暂停，支持 `1x / 3x / 5x` 倍速。
- **地图操作**：滚轮或右上角 `+/-` 缩放，按住左键拖拽平移，可随时切换 **政治 / 地形 / 补给** 三大地图模式。
- **部队调动与进攻**：左键点击驻有己方部队的省份选中该省所有师，随后 **右键点击相邻省份**（或在军事面板开启“指令移动”后左键点击）即可行军或向交战国发起进攻。
- **内政与外交**：在左侧面板管理部队招募、军工产线分配、科技研发、国家焦点与外交宣战；选中己方省份后可在左下角检查器中建造民用工厂、军用工厂、基础设施或陆地要塞。
- **存档与读档**：点击顶部 `💾` / `📂` 按钮可将完整世界状态序列化并保存至浏览器本地存储。
