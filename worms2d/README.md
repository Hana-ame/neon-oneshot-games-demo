# 百战天虫 2D（Worms 2D Web）

经典回合制 2D 炮兵策略游戏 **百战天虫（Worms 2D）** 的原生 HTML5 网页完整复刻版，包含像素级可破坏地形、风力弹道物理、6 种经典武器、战术 AI、Web Audio 程序化音效、Node.js 自动化测试与技术报告。

## 快速开始

- **即开即玩**：直接用浏览器打开 `dist/worms2d-standalone.html`
- **模块化运行**：在项目根目录运行 `python3 -m http.server 8080`，浏览器打开 `http://localhost:8080`
- **运行自动化测试**：需要 Node.js 18+，执行：
  ```bash
  npm test
  ```

## 操作键位

| 按键 | 功能 |
| :--- | :--- |
| `A / D` 或 `← / →` | 左右移动（自动爬坡） |
| `W / S` 或 `↑ / ↓` | 调整瞄准角度 |
| `Enter` 或 `J` | 向前跳跃 |
| `Backspace` 或 `K` | 高跳后空翻 |
| 按住 `Space` 松开 | 蓄力发射（霰弹枪/炸药即点即用） |
| `1 ~ 6` | 快速切换 6 种武器 |
| 鼠标拖拽画布 | 自由平移战场视角 |
| 空袭模式下点击地图 | 呼叫 5 枚导弹轰炸点击位置 |
| `P` | 暂停 / 继续 |

详细架构与算法说明请参阅 `docs/TECHNICAL_REPORT.md`。
