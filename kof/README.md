# KOF Web Arcade · 拳皇网页格斗复刻项目

基于原生 HTML5 Canvas 2D、Web Audio API 与零依赖 ES Modules 打造的《拳皇（The King of Fighters '97/'98）》风格网页格斗游戏完整项目，包含模块化引擎源码、18 项自动化单元测试与集成测试、完整技术报告以及单文件可玩构建版。

## 核心特性

- **4 名经典风格角色与完整帧数据**：草薙京（均衡压制）、八神庵（高速爆发）、不知火舞（灵动牵制）、特瑞·博加德（力量重击），均配备轻重拳脚、下段扫腿、空中跳攻、3 个必杀技与 1 个超必杀技。
- **经典拳皇战斗机制**：24 帧方向输入缓冲（支持 `↓↘→`、`→↓↘`、`↓↙←`、`↓↘→↓↘→` 搓招，同时提供一键快捷必杀）、打击顿帧（Hitstop）、必杀/超必杀取消（Special/Super Cancel）、连击伤害递减、站蹲防与破防（Guard Crush）、紧急回避翻滚（无敌穿身）、气槽积攒与超必杀暗屏特写。
- **4 种游玩模式与 3 个视差舞台**：3v3 经典组队战（胜者留场并回复部分生命值）、1v1 街机三局两胜、本地 2P 双人对战、训练模式（无限气血与判定框可视化调试）。
- **复古街机合成音效**：纯 Web Audio API 实时合成打击音、防御金属音、破防音效、超必杀闪光与街机摇滚风格 BGM，无需外部音频文件。
- **零外部运行依赖**：无需 `npm install`，Node.js 18+ 原生即可运行测试与打包；双击 `dist/kof_web_game.html` 即可在浏览器直接开玩。

## 快速开始

### 1. 直接游玩
在任意现代浏览器中打开 `dist/kof_web_game.html` 即可开始游戏（支持键盘与屏幕触控按键）。

### 2. 运行自动化测试（需 Node.js >= 18）
```bash
npm test
```

### 3. 重新构建单文件发布版
```bash
npm run build
```

## 操作说明

| 动作 | P1 键盘按键 | P2 键盘按键（2P 模式） |
| :--- | :--- | :--- |
| 移动 / 跳跃 / 下蹲 | `W` `A` `S` `D` | 方向键 `↑` `←` `↓` `→` |
| 轻拳 / 重拳 | `J` / `U` | 小键盘 `1` / `4` |
| 轻脚 / 重脚 | `K` / `I` | 小键盘 `2` / `5` |
| 快捷必杀（配方向切换3招） | `O`（`W+O` 对空，`后+O` 突进） | 小键盘 `3` |
| 快捷超必杀（消耗 1 格气） | `L` | 小键盘 `6` |
| 紧急回避翻滚 | `Space` 或 `Left Shift` | 小键盘 `0` |
| 暂停 / 继续 | `Esc` | `Esc` |
