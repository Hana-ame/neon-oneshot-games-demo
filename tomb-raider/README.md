# 网页古墓丽影：太阳圣殿（Tomb Raider Web）

一款零外部依赖的 HTML5 Canvas 2D 古墓探险动作解谜网页游戏，包含模块化源码、自动化测试套件、技术报告及单文件构建脚本。

## 快速开始

- **直接试玩**：用任意现代浏览器打开 `index.html` 即可开始游戏（无需搭建服务器，支持桌面键鼠与移动端虚拟手柄）。
- **运行自动化测试**（需 Node.js >= 18）：
  ```bash
  npm test
  ```
- **重新构建单文件版本**：
  ```bash
  npm run build
  ```

## 操作说明

| 按键 | 功能 |
| :--- | :--- |
| `A` / `D` 或 `←` / `→` | 左右移动 / 推石箱 |
| `W` / `S` 或 `↑` / `↓` | 攀爬藤蔓 / 抓崖上翻或松手 |
| `Space` | 跳跃 / 抓崖上翻 |
| `Shift` / `K` | 翻滚闪避（含无敌帧） |
| `J` / `Z` / 鼠标左键 | 双枪射击（可远程激活拉杆） |
| `E` / `F` | 近身触发古墓拉杆 |
| `P` / `ESC` | 暂停 / 继续 |
| `R` | 重新开始当前关卡 |
