# RimWeb（网页版边缘世界）技术架构与测试报告

## 1. 项目概述

**RimWeb** 是一款基于浏览器原生技术栈（HTML5 Canvas 2D、ES Modules、Web Audio API）实现的《边缘世界》（RimWorld）风格殖民地模拟游戏完整项目。项目采用**无头模拟引擎（Headless Simulation Engine）与视图层解耦**的架构设计，实现了不依赖任何第三方运行时框架的零依赖运行与打包方案，同时具备可在 Node.js 环境中直接执行的自动化单元测试与集成测试套件。

### 核心功能清单
- **程序化地图与生态生成**：56×42 网格地图，支持草地、肥沃土壤、泥土、沙地、浅水、深水、岩石地面 7 种地形，以及橡树、浆果丛、花岗岩山体、压实钢铁矿、金矿脉 5 类自然资源。
- **殖民者 AI 与生存系统**：内置饱食度、精力、娱乐、生命值、心情与动态「想法（Thoughts）」标签；支持 1–4 级自定义工作优先级矩阵（医疗、烹饪、建造、种植、采矿、研究）及征召战术控制。
- **建造、区域与电力防线**：支持 10 类建筑（木墙、石墙、木门、木床、篝火灶台、火把、太阳能板、自动机枪塔、沙袋掩体、研究台）、储存区/种植区框选与 4 项科技树研究。
- **昼夜光照、天气与 AI 叙事者**：90 秒完整昼夜循环与平滑环境光衰减、夜间火把/篝火径向暖光照明、4 种动态天气（晴朗、小雨、热浪、寒潮）以及 5 类叙事者事件（海盗袭击、空投补给、流浪者加入、商队赠礼、天气突变）。
- **状态持久化**：支持 `localStorage` 本地存取与完整 JSON 字符串导入/导出。

## 2. 系统总体架构

项目遵循「模拟逻辑与表现层严格分离」的工程原则，划分为 4 个清晰层次：

```text
┌───────────────────────────────────────────────────────────┐
│                  交互与表现层 (Browser UI)                  │
│   index.html + styles.css + src/main.js + src/audio.js    │
├───────────────────────────────────────────────────────────┤
│               Canvas 2D 渲染层 (src/renderer.js)           │
│     视口裁剪 · 分层精灵绘制 · 昼夜遮罩与径向光源混合        │
├───────────────────────────────────────────────────────────┤
│              无头模拟核心层 (src/simulation.js)            │
│  时钟/天气 · 电网与炮塔 · 作物生长 · 叙事者 · 序列化存档    │
├─────────────────────────────┬─────────────────────────────┤
│   AI 与实体层               │   地图与寻路层               │
│   src/ai.js · colonists.js  │   src/mapGen.js             │
│   优先级调度 · FSM · 战斗AI │   src/pathfinding.js (A*)   │
└─────────────────────────────┴─────────────────────────────┘
```

### 零依赖双形态构建管线
- **开发与测试形态**：以原生 ES Modules（`"type": "module"`）组织源码，Node.js 18+ 可直接通过 `node --test` 导入并运行所有模拟层测试，无需 Babel/Webpack 编译。
- **单文件分发形态**：`scripts/bundle.mjs` 按拓扑依赖顺序（`constants → mapGen → pathfinding → colonists → ai → simulation → audio → renderer → main`）剥离模块语法并封装为 IIFE，内联 `styles.css` 输出单文件 `dist/web-rimworld.html`（约 119 KB），双击即可离线运行。

## 3. 核心算法与关键实现

### 3.1 确定性伪随机与程序化地形生成（`src/mapGen.js`）
- **Mulberry32 PRNG**：采用 32 位整型状态机 `createRng(seed)`，确保相同种子在任意浏览器或 Node 环境下生成完全一致的地图与初始殖民者属性，便于回归测试与种子分享。
- **多层二维平滑值噪声**：使用双层频率叠加（主海拔噪声 0.09 + 细节噪声 0.22）结合 Smoothstep 插值 $u(t) = 3t^2 - 2t^3$ 生成连续自然的湖泊、沙滩、肥沃盆地与山脉矿区。
- **出生点保底机制**：对地图中心半径 7.5 格区域执行海拔平滑，并保证近处存在钢铁矿脉、浆果丛、树木及默认储存区，避免极端随机导致前期卡死。

### 3.2 二叉最小堆 A* 寻路算法（`src/pathfinding.js`）
- **开放列表优化**：手写 `MinHeap` 二叉最小堆，将节点弹出与插入复杂度控制在 $O(\log N)$；配合 `Float32Array`（`gScore`）、`Int32Array`（`cameFrom`）与 `Uint8Array`（`closed`）定型数组降低 GC 压力。
- **地形代价与防对角穿墙**：支持 8 方向移动，对角步长取 $\sqrt{2} \approx 1.414$ 并乘以地形/建筑移动系数（如浅水 2.2×、沙袋 1.6×、岩石地面 0.9×）；若对角相邻两正交格中任一不可通行，则禁止斜向穿越，杜绝「穿墙角」现象。
- **邻接目标模式（`allowAdjacent`）**：针对采矿（不可通行的矿脉）和建造墙体等任务，当路径搜索到达目标八邻域内即视为抵达，兼顾寻路准确性与任务可用性。

### 3.3 优先级调度与有限状态机 AI（`src/ai.js`, `src/colonists.js`）
每个殖民者在每个模拟步长（`tick`）中遵循确定性决策优先级：
1. **征召覆写**：处于征召态时仅执行玩家下达的 `MOVE_DRAFTED` 战术移动或自动射击 8.5 格内敌对目标。
2. **应急自卫**：非征召状态下，若 6.5 格内出现掠夺者，自动切入 `FIGHT` 状态迎击。
3. **生理底线**：饥饿度 `< 28` 触发进食；精力 `< 24`（或夜间 `< 58`）优先寻找空闲木床休眠；娱乐 `< 22` 前往篝火/火把旁放松。
4. **工作优先级队列**：按用户配置的 1–4 级优先级依次检索医疗、烹饪、建造、种植/砍伐/采摘、采矿与研究任务，并通过 `getReservedTiles` 互斥锁防止多名殖民者扎堆抢占同一施工点。

### 3.4 电力网络、昼夜光照与渲染优化（`src/simulation.js`, `src/renderer.js`）
- **动态电网与炮塔**：太阳能板输出随昼夜环境光系数 `getAmbientLight()`、天气衰减系数（雨天 0.65×、热浪 1.2×）以及「高能光伏」科技动态变化；当总发电量满足总负荷时，自动机枪塔每 0.75 秒自动索敌射击 8.5 格内目标。
- **视口裁剪（Frustum Culling）**：渲染器仅遍历当前相机可见矩形范围内的网格（`minX..maxX`, `minY..maxY`），在 56×42 甚至更大地图下保持稳定 60 FPS。
- **昼夜光照与混合模式**：夜间叠加半透明深蓝环境光遮罩，并在 `globalCompositeOperation = 'lighter'` 模式下为已建成的篝火与火把绘制径向渐变暖光。

## 5. 局限性与后续扩展方向

1. **室内房间与温度热力学**：当前温度为全局昼夜+天气模型，后续可基于 Flood-Fill 房间识别引入屋顶、墙体隔热与空调/取暖器局部温控。
2. **物品搬运实体化**：当前采集与烹饪直接汇入殖民地全局库存，后续可将地面掉落物实体化并增加专职搬运（Hauling）任务与储存区过滤规则。
3. **更深度的战斗与社交**：可扩展装备武器库、掩体命中率衰减、殖民者间好感度社交事件及伤病包扎部位系统。
